Installation locale

La liseuse est un site statique : elle se lit en ligne, se garde en hors-ligne, et s'installe sur n'importe quelle machine avec un simple serveur de fichiers. Trois niveaux, du plus simple au plus complet.

1. Mode hors-ligne (rien à installer)

Le site est une PWA : à la première visite, le corpus (299 textes, index, pages clés) se met en cache dans le navigateur. Une fois le marque-page fermé et la connexion coupée, la lecture continue — le Service Worker sert les pages depuis le cache.

Pour l'« installer » comme une application : bouton Installer dans la barre d'adresse (desktop) ou Ajouter à l'écran d'accueil (mobile). Les mises à jour de contenu se proposent automatiquement par une bannière de version.

2. Copie locale sur votre machine

Le site n'est que des fichiers : le dépôt le contient, un serveur statique suffit. Depuis un terminal : 

git clone https://github.com/Sol-Vivant/Publications.git
mkdir -p pubroot/Publications
ln -s "$(pwd -P)/Publications/liseuse" pubroot/Publications/liseuse
cd pubroot
python3 -m http.server 8080
# → http://localhost:8080/Publications/liseuse/

Le chemin /Publications/liseuse/ fait partie de l'URL : le site est préfixé pour GitHub Pages, et le lien symbolique reproduit ce chemin en local — liens, manifeste et Service Worker fonctionnent alors à l'identique de la version en ligne.

Tout serveur statique convient (python3 -m http.server, npx serve, nginx, Caddy…). Aucune base de données, aucun langage serveur.

3. Rebuild complet (contributeurs)

Le pipeline de génération vit dans le dépôt de développement. Il part de la base documentaire et produit le site (extraction → bundle Markdown → ~8 000 pages HTML → Service Worker) : 

# Prérequis : Node ≥ 20, Python 3, pandoc ≥ 3.10
export ASTRO_BASE=/Publications/liseuse/
bash tools/liseuse/build.sh --db sol_vivant.db --force

Détail complet (tests, exports EPUB/PDF, cache incrémental) dans le README du dépôt de développement.
