Chantier 14 — Transformer la gestion de lazote
Leviers : Légumineuses ; H2 électrolytique ; OAD ; recyclage urines/digestats.
Verrous : Silos inadaptés ; sélection génétique ; débouchés ; formation.
Pertinence : CŒUR DE CORPUS : toutes fiches N, légumineuses, fertilité, azote (rapport p. 137-146).

Chantier 15 — Maintenir les élevages résilients
Leviers : Baisse cheptels sélective ; herbagers ; légumineuses prairies ; relocalisation alim.
Verrous : Dépendance soja ; attractivité métier ; revenus.
Pertinence : CŒUR DE CORPUS : fiches élevage, prairies, haies, fumier (rapport p. 147-155).

Chantier 18 — Déployer bioénergies soutenables
Leviers : Méthanisation territoriale ; CIVE ; digestats ; bois.
Verrous : Conflits usage biomasse ; emploi ; pilotage.
Pertinence : PARTIEL : méthanisation + CIVE + digestats (liens ch.14) (rapport p. 173-183).

Chantier 19 — Préserver puits C naturels agri+forestiers
Leviers : Prairies ; couverts ; haies ; agroforesterie ; diversification forêt.
Verrous : Soutien économique ; formation ; pérennité stockage ; climat.
Pertinence : CŒUR DE CORPUS : fiches stockage C, agroforesterie, forêts, sols (rapport p. 184-197).

Chantier 21 — Emploi et compétences — transversal
Leviers : Formation, reconversion, apprentissage, attractivité.
Verrous : Concurrence recrutement, formation lente, résistance culturelle.
Pertinence : PARTIEL — maraîchage relocalisation +25k ETP, renouvellement générations agri prioritaire (rapport p. 278-297).

Chantier 22 — Cuivre — matériau critique
Leviers : Substitution, recyclage max, sobriété matière.
Verrous : Concentration géopolitique (Chili/Pérou/RDC=50%), raffinage Chine 45%, délais mining 15-20 ans.
Pertinence : FAIBLE — matériau critique infrastructure énergétique (réseaux, VE, EnR), impact indirect territoires mining (rapport p. 298-311).

Les chantiers « hors périmètre » (transports, logement, énergie, industrie, numérique) sont listés dans le tableau pour la complétude du plan — sans reproduction de leur contenu.
