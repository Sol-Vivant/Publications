# Publications — Manifeste

Dépôt public des sorties du projet « Le Sol Vivant cet Holobionte »
(auteur : Jean-Michel Juzan, licence MIT). La source de vérité (DB,
scripts, agents) vit dans le dépôt de développement ; ici ne vivent que
les sorties publiées.

## Entrées principales

| Chemin | Contenu |
|---|---|
| `index.html` | Page d'accueil — trois entrées (Liseuse, technique, Outils) |
| `liseuse/` | Site statique Astro (Liseuse du corpus) : fiches, thésaurus, cards, chaînes, outils de terrain. PWA hors-ligne + exports. |
| `technique/` | Guide technique : `architecture.md`, `gestion_sessions.md`, `api_externes.md`, `guide_git.md`, `reproduire_le_patron.md` + `index.html` |
| `Outils/` | Outils low-tech indépendants du corpus : `foursolaire.html`, `puitcanadien.html`, `simulateurparabolle.html` + `index.html` |
